\subsection{Document-Level Cross-Validation Protocol}
To quantify variability due to corpus partitioning, we replaced the original
single-split analysis with five-fold cross-validation at the CTI-report level.
The 52 reports were assigned to five mutually exclusive folds using a fixed
assignment seed (42). Entity- and relation-label counts were used only to
improve approximate fold balance. All sentences and annotations originating
from the same report remained in the same outer fold, preventing report-level
context leakage. In outer iteration $k$, fold $k$ was used for testing. Five
complete reports were selected as validation data only from the remaining four
folds using a deterministic label-aware procedure; the other non-test reports
were used for training. Consequently, every report served as test data exactly
once, and no test report was used for model selection. STIXnet-only and the
proposed hybrid used identical partitions. Each outer iteration was run
with five model seeds (42, 123, 2024, 3407, and 777); model selection and all
hyperparameter decisions used validation data only. We report the mean and
sample standard deviation across the five outer-fold means, together with the
per-fold paired difference between the two systems. The previously reported
five-seed fixed-split results are retained only as a secondary reproducibility
check.
